## Uso de `imagem_url` e conferência

- `src/services/produtoService.js` transforma `imagem_url` em `product.image` para Home, Loja, Produto e consultas do Carrinho.
- Administração usa `produto.imagem_url` diretamente no mesmo `ProductImage`.
- `ProductImage` mantém o fallback existente para URL vazia, favicon e erro de carregamento. Não foi colocado um mapeamento estático no lugar dos dados do Supabase.
- Após disponibilizar os arquivos no host, editar os dois produtos pelo painel e escolher “Usar URL”, preenchendo os caminhos prontos acima. Ou usar “Enviar do computador” para hospedar cada WebP no Storage e vincular a URL pública obtida.
- Os dois WebP foram conferidos nas cinco telas reais em uma prévia local com Supabase **simulado**, sem requisições de escrita remota: imagens carregadas, `object-fit: contain`, sem overflow. Os caminhos ainda precisam ser associados manualmente aos produtos reais; até lá os placeholders existentes continuam nas telas reais.
